# Changelog

## 0.1.0 — first complete build

* Benchmark (Digital Giza) moved to `reference/`; measured inventory and architecture contract written.
* Scoped-module bundler: every module (and three.js r160) in its own scope; JSON imports; 8 MB size gate.
* PM engine: 12 summaries, 77 work packages, all four link types, PERT, CPM, crashing, fast-tracking, EVM with
  earned schedule, 32 risks, 16 stakeholders, 12 resources, 17 procurement packages, gates G0–G4, change control,
  Scrum backlog, quality control, Monte Carlo in a Web Worker, MSPDI/CSV export; 78 unit tests.
* World: runway-aligned airfield with Annex 14-style markings and WBS-driven extension phases, AGL with PAPI and
  approach-light flasher, enterable terminal with live FIDS, tower cab, landside, city backdrop, construction sites.
* Rendering: NOAA sun for Hyderabad, PMREM lighting, weather (haze, dust, monsoon, fog, heat), FXAA/TAA, depth of
  field, motion blur, lens flare; procedural PBR materials incl. Ajrak screens.
* Vehicles, aircraft (fictional liveries), crowds and Operations-mode traffic with benefits KPIs.
* UI: Indus Night HUD, 25 CLO-tagged panels, onboarding, touch, accessibility, Urdu labels.
* MEHRAN AI: offline rule engine, 80 intents, 317-term glossary, optional live Claude mode with approvals, voice.
* Game: 16 missions, 38 decision events, XP/badges/scorecard/certificate, 20-beat tour, 139-question quiz bank.
* Procedural audio. Facts file with 55 graded entries; case-study cards.
* Docs: README, presenter guide, course mapping, benchmark parity, facts & sources, test report.
