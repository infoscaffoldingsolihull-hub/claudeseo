# Bagh-e-Shahi Manor

A single-file, offline, real-time digital twin of a royal mansion in DHA Phase VI,
Lahore — and of the 516-day project that builds it.

**Run it:** double-click `dist/RoyalMansion.html`. No server, no install, no network.

---

## What it is

A walkable royal mansion — basement, ground floor, first floor, 894 m² of covered
area on a two-kanal plot — welded to a full PMBOK-style project simulation. The
building is not illustrated by the schedule; it is **derived** from it. Drag the
timeline and the house builds itself, because the model asks the programme what
fraction of each work package is earned on that day and cuts the geometry that
package paid for.

## What it does

- **Walk, orbit, fly or take a guided tour** of the finished house.
- **Press <kbd>E</kbd> on anything.** Doors open on their real hinge lines. Everything
  else opens an inspection card with its material, dimensions, work package, BOQ
  line, rate, quantity and **cost in Pakistani rupees**.
- **Scrub 516 days** from a bare plot to handover, and watch a live site: a tower
  crane that climbs with the frame and runs a real duty cycle, masons laying brick on
  the wall line, a scaffold that erects with the masonry and is struck as the
  cladding finishes, an excavator working a formation that drops lift by lift.
- **Five real times of day** — dawn, noon, golden hour, dusk, night — at the true
  solar position for Lahore on any day of the year.
- **WBS X-ray** strips the finishes and colours what remains by building system.
- **A twelve-tab dashboard**: charter, WBS, schedule, cost/EVM, BOQ, risk, resources,
  quality gates, procurement, stakeholders, Monte Carlo, and an advisor that reads
  the numbers back in words.

## Building it yourself

```sh
node tools/check-mansion.mjs     # static gate: imports, exports, symbol collisions
node tools/build-mansion.mjs     # flatten 33 modules + three.js into one HTML file
node tools/smoke-mansion.mjs     # 63 checks in headless Chromium, from file://
node tools/smoke-mansion.mjs --shots   # …and regenerate the screenshots
```

All three must pass before the file ships. They are gates, not suggestions: the
static checker exists because the flattening build puts every module in one scope,
where two modules declaring the same top-level name would silently shadow one
another.

## Read this before you present it

The rates are an internally consistent illustrative model for high-end Lahore
residential construction in 2025–26 — **not a verified quotation** — and the
as-built programme is **simulated, not observed**. Both are stated plainly, with the
rest of the limitations, at the end of the technical report and throughout the
defence Q&A. The structure is what is being defended; the inputs live in one file
and a real tender can replace them.
